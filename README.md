# mlemley/homebrew-tools

Homebrew tap for my CLI tools.

## Install

```sh
brew tap mlemley/tools
brew install opencode-variants
```

## Formulae

| Formula | Description |
|---------|-------------|
| [`opencode-variants`](Formula/opencode-variants.rb) | Per-directory OpenCode model routing (cloud/hybrid/all-local) via generated direnv configs. Command: `ov`. |
